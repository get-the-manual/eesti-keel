# **Impersonaal** (Безличная форма глагола)

Безличная форма глагола (**Impersonaal**) - это форма, которая заменяет подлежащее. Мы используем её, когда неважно, **кто именно** совершает действие, или когда мы говорим о людях вообще («говорят», «делают», «строят»).

С этой формой никогда не используются слова «я», «ты», «мы» и т.д. Глагол сам по себе уже значит «люди делают».
    
Если мы называем предмет, над которым совершается действие, он часто ставится в **Partitiiv** (партитив). Если действие завершено и охватывает весь предмет, дополнение стоит в **Nimetav**: _Palk saadakse kuu lõpus._	

Используется одна форма для всех — нет лица и числа.


## Настоящее время (olevik)

### Положительная форма 

Окончание выбирают по форме **da-инфинитива**.

**1. -takse** (основной вариант)  
da-инфинитив из двух и более слогов на **-da** или **-ta**: окончание **-da/-ta** заменяем на **-takse**.

**Примеры:**

* kirjutama (kirjutada) → kirjutatakse  
* töötama (töötada) → töötatakse  
* õppima (õppida) → õpitakse  
* rääkima (rääkida) → räägitakse  
* vaatama (vaadata) → vaadatakse  

---

**2. -dakse**  
односложный da-инфинитив на **-da**: окончание **-da** заменяем на **-dakse**.

**Примеры:**

* saama (saada) → saadakse  
* jääma (jääda) → jäädakse  
* laulma (laulda) → lauldakse  
* ütlema (öelda) → öeldakse  

---

**3. -akse**  
da-инфинитив оканчивается на **-a** без **d/t** (tulla, minna, olla, süüa, teha): окончание **-a** заменяем на **-akse**.

**Примеры:**

* tulema (tulla) → tullakse  
* minema (minna) → minnakse  
* olema (olla) → ollakse  
* jooma (juua) → juuakse  
* sööma (süüa) → süüakse  
* käima (käia) → käiakse  
* tegema (teha) → tehakse (делают)  

Есть исключения, например sõitma (sõita) → sõidetakse.  



### Отрицательная форма

**Образование:**

```
ei + основа глагола + -ta/-da
```

**Примеры:**

* ei räägita (не говорят)  
* ei tehta (не делают)  
* ei sööda (не едят)  
* ei kirjutata (не пишут)

## Прошедшее время (minevik)

### Положительная форма

```
основа + -ti/-di
```

**Примеры:**

* räägiti (говорили)  
* tehti (сделали)  
* söödi (ели)  

### Отрицательная форма

```
ei + основа + -tud/-dud
```

**Примеры:**

* ei räägitud (не говорили)  
* ei tehtud (не сделали)  
* ei söödud (не ели)
